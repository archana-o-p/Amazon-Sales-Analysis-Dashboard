# Amazon Sales Analysis Dashboard

## Overview

This project presents an interactive Amazon Sales Analysis Dashboard developed using Microsoft Excel. The dashboard transforms raw sales data into meaningful business insights through KPI tracking, trend analysis, and interactive visualizations.

## Objectives

* Analyze sales performance across multiple years.
* Monitor revenue and order trends.
* Evaluate customer purchasing behavior.
* Identify top-performing brands and product categories.
* Visualize key business metrics through an interactive dashboard.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Data Cleaning
* Conditional Formatting
* Canva

## Key KPIs

* Total Customers: 100,000
* Total Revenue: ₹91.83 Million
* Total Orders: 100,000
* Units Sold: 300,100
* Average Order Value: ₹918

## Dashboard Features

* Year-wise filtering
* Brand-wise analysis
* Category-wise analysis
* Revenue trend analysis
* Seller performance tracking
* Payment preference analysis
* Order status breakdown
* Product demand analysis

## Key Insights

* United States generated the highest revenue among all countries.
* Delivered orders accounted for the majority of completed transactions.
* Electronics showed the highest product demand.
* CoreTech emerged as one of the top revenue-generating brands.
* Revenue peaked in 2023 before showing a slight decline in 2024.
